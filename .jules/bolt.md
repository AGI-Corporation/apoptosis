## 2026-04-18 - [Optimization of analytical ODE solution in Stan]
**Learning:** Combining multiple compartment model components into a single algebraically simplified analytical solution significantly reduces the number of expensive `exp()` calls and function call overhead in Stan's inner sampling loop. Specifically, merging $R(t)$, $Q_a(t)$, and $Q_c(t)$ into a single expression for $y(t)$ allowed reducing `exp()` calls from 6 down to 3 for the $t \ge t_d$ case. Additionally, using `expm1()` for the $t < t_d$ case improved numerical stability and eliminated one `exp()` call.
**Action:** Always look for algebraic simplifications in analytical solutions to ODE systems. Prioritize reducing transcendental function calls within loops and use specialized functions like `expm1()` or `log1p()` for better precision and performance at boundaries.
