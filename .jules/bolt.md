## 2026-04-28 - Stan Analytic Solution and Loop Hoisting
**Learning:** Significant performance gains in Stan are achieved by combining algebraic simplification of analytic ODE solutions with loop hoisting. Reducing $O(N)$ transcendental function calls (`exp()`) by pre-calculating clone-level parameters in the `transformed parameters` block and using numerically stable `expm1()` provided a measurable speedup. Hard-coding a small floor (e.g., `1e-9`) in the return value ensures numerical stability and prevents `log(0)` errors in log-likelihood calculations without noticeably affecting the model results.
**Action:** Always check for redundant $O(N)$ calculations and invariant exponentiations inside observation loops in Stan models. Hoist them to `transformed parameters` or `generated quantities` blocks as appropriate. Use `expm1()` and `log1p()` for improved precision.
